Project Title

Banking Customer & Financial Analytics

Description

An end-to-end Data Analytics project focused on analyzing banking customer profiles, account balances, transaction behavior, loan portfolios, credit exposure, and anomalous transactions. The project uses Python for data cleaning, preprocessing, and Exploratory Data Analysis (EDA), followed by Power BI for interactive dashboard development and business-focused insights. The analysis is designed to identify transaction trends, customer patterns, loan performance, credit utilization, and potential risk areas to support data-driven decision-making.
