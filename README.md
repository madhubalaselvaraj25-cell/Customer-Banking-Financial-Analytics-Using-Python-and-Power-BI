# Project Title

Customer Banking & Financial Analytics

## Description

An end-to-end Data Analytics project focused on analyzing banking customer profiles, account balances, transaction behavior, loan portfolios, credit exposure, and anomalous transactions. The project uses Python for data cleaning, preprocessing, and Exploratory Data Analysis (EDA), followed by Power BI for interactive dashboard development and business-focused insights. The analysis is designed to identify transaction trends, customer patterns, loan performance, credit utilization, and potential risk areas to support data-driven decision-making.

### Original Dataset Source

https://github.com/ahsan084/Banking-Dataset/blob/main/Comprehensive_Banking_Database.csv

## Getting Started

### Dependencies

- Python 3.x
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Microsoft Power BI

### Installing

1. Load the banking dataset into Google Colab.
2. Install the required Python libraries if needed.
3. Open the Power BI `.pbix` file using Power BI Desktop.

### Executing program

1. Load and explore the dataset.
2. Clean and preprocess the data.
3. Perform EDA and create visualizations.
4. Analyze customer, transaction, loan, credit card, feedback, and anomaly data.
5. Develop the Power BI dashboard.
6. Identify insights and business recommendations.

## Help

- Check the dataset path if Python cannot load the data.
- Refresh the dataset in Power BI if visuals are not updated.
